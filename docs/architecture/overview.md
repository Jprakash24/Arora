# Architecture overview

AURA is split into two independently runnable applications:

- **Frontend:** `frontend/` contains the React/Vite single-page application. Routes are in `src/routes/`, page-level screens in `src/pages/`, reusable UI in `src/components/`, login state in `src/context/`, and HTTP access in `src/services/`.
- **Backend:** `backend/src/Aura.Api/` contains the ASP.NET Core 8 API. `Program.cs` configures HTTP middleware and maps endpoints; `Models/` contains EF Core entities/options; `Services/` contains AI/email services and billing/maintenance logic.

The frontend calls the API at `http://localhost:5000` by default. Set `VITE_API_URL` in `frontend/.env` to override it.

Development mode uses SQLite so the application can run without Docker. Other environments use PostgreSQL. Identity stores users and roles; generation history and Razorpay orders are stored in the API database. AI output is generated by Anthropic, and payment credits are granted only by the verified Razorpay webhook.

There is no Node.js backend, and there are no automated test projects in the current codebase.
